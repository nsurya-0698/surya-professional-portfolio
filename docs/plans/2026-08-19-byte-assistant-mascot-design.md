# Byte Assistant Mascot Design

## Goal

Replace the abstract assistant orb with a small, memorable pixel-art border collie named Byte while preserving the portfolio assistant's existing functionality and professional tone.

## Approved character

- Compact black-and-white border collie inspired by the supplied reference image without copying it exactly.
- Friendly, intelligent expression with readable eyes, upright ears, white facial blaze, white chest, small paws, and a wagging tail.
- Crisp pixel-art silhouette designed to remain readable around 50 px.
- No circular frame around the character.

## Behavior

- Idle: subtle breathing, blinking, ear twitch, and occasional tail wag.
- Greeting: small paw wave.
- Waiting: curious head tilt.
- Thinking: focused expression and restrained processing motion.
- Success/responding: brief happy bounce.
- Failure: concerned expression without alarming effects.
- Look directions: subtle eye/head attention toward pointer position where supported.
- Reduced motion: stable neutral pose.

## Integration

- Closed launcher remains approximately 50 px and does not cover primary content.
- Clicking Byte opens the existing assistant panel.
- Existing tooltip, keyboard behavior, assistant states, and accessible button label remain intact.
- Message avatars may use a simplified Byte frame after launcher validation.
- Work remains local for user review; nothing is pushed.
