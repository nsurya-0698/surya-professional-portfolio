# NST Flow Logo Design

## Objective

Replace the current framed NST monogram with a distinctive, navigation-scale brand mark while preserving the initials `NST`.

## Approved direction

Use a frameless continuous-line monogram. The `N` flows into an `S` and resolves into a `T`, creating one compact visual gesture rather than three overlapping type characters.

## Visual system

- Preserve the portfolio's teal-to-violet accent palette.
- Use bold geometric strokes that remain legible at 40–48 px.
- Avoid hexagons, shields, fine outlines, serif lettering, and decorative underlines.
- Keep the silhouette compact and balanced for desktop and mobile navigation.
- Add only a restrained light sweep; the mark must remain clear without animation.

## Interaction and accessibility

- Retain the existing home link and accessible label.
- Respect `prefers-reduced-motion` by disabling the light sweep.
- Keep hover motion subtle and avoid continuous floating that competes with navigation.

## Validation

- Verify at 48 px desktop and 40–44 px mobile sizes.
- Confirm contrast on the transparent navigation background.
- Run the production build and visually inspect the local preview before pushing.
